# peace. | A practice of being alive

A mobile-friendly, Buddhist-inspired daily practice app for acceptance, presence, joy, connection, and purposeful effort.

## Run it locally
Open `index.html` in a modern browser. No build step or dependencies are required.

## Publish with GitHub Pages
1. Create a new GitHub repository, for example `peace-app`.
2. Upload `index.html` to the repository's root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your main branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. The Pages panel will show your site URL.

## Data and privacy
- Check-ins, journal entries, pause reflections, and saved moments are stored in this browser's `localStorage`.
- They are not sent to GitHub or any server.
- Local browser storage does not automatically sync between devices or browsers.
- Use **Export my data** regularly to download a JSON backup. Keep that file somewhere safe.
- Use **Import backup** to restore a previous export. Import merges entries; export your current data first as a precaution.
- Clearing browser/site data can erase local records. This app is a personal reflection tool, not a clinical assessment.

## Included
- Daily check-in with 1–10 ratings for mood, energy, presence, acceptance, joy, connection, and purposeful effort
- Two dated open-text reflections: “How did today go?” and “A good thing, silver lining, or something I did well”
- Optional positive-point activity game across Mind, Body & Care, Connection & Joy, Inner Work, and Purposeful Effort; no penalty points
- Date-based editing and historical check-ins
- Pause flow for overthinking, strong emotions, control, disconnection, and setbacks
- Eight short philosophy lessons with practical exercises
- Random everyday joy prompts
- Journal, period averages, simple trends, and recurring emotion counts
- JSON export/import for backup
